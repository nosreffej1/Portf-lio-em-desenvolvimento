# Portfólio — Jefferson Gabriel

Portfólio pessoal de **Jefferson Gabriel**, Desenvolvedor Full Stack Pleno
(PHP / Yii2, APIs REST e automação de processos corporativos).

Site estático em **HTML, CSS e JavaScript**, sem dependências de build.

## Design

Tema escuro, sóbrio e moderno:

- Fundo grafite/navy (`#0C0F16`) com brilho ambiente sutil
- Acento esmeralda (`#34D399`) e azul de apoio (`#5EA0F2`)
- Tipografia serifada editorial (**Fraunces**) + **Inter** no corpo + **JetBrains Mono** nos rótulos

## Estrutura

```
index.html   → marcação e conteúdo
style.css    → design system completo (tokens, layout, responsivo)
script.js    → menu mobile, scrollspy, header e animações de entrada
images/      → previews dos projetos
```

## Como rodar

Abra `index.html` no navegador, ou sirva localmente:

```bash
python3 -m http.server
```
